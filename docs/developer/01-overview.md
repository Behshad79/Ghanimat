# ۰۱ · نمای کلی، اجرا و ساختار

## محصول

غنیمت فروشگاه اینترنتی کالای اصل وارداتی است با سه پنل: **ویترین (سایت مشتری)**، **پنل فروشنده/شعبهٔ همکار** و **پنل مدیریت**. این مخزن پروتوتایپ کامل و قابل‌اجرای **پنل مدیریت** است، با دادهٔ نمونهٔ واقع‌گرا. هر دکمه کار واقعی انجام می‌دهد (روی دادهٔ نمونه) و هر حالت (خالی، خطا، بارگذاری، بدون دسترسی، آفلاین) پیاده شده است.

این نسخه بک‌اند ندارد؛ **رفتار، متن، چیدمان و قانون‌ها نهایی‌اند** و باید عیناً پیاده شوند. آنچه باید ساخته شود در [10-production-plan.md](10-production-plan.md) آمده است.

## فناوری

| لایه | انتخاب | نسخه |
|---|---|---|
| زبان | TypeScript (strict) | 7 |
| رابط | React | 19 |
| مسیریابی | react-router-dom | 7 |
| استایل | Tailwind CSS (با توکن‌های CSS) | 4 |
| ساخت | Vite | 8 |
| آیکون | lucide-react | — |
| QR | qrcode-generator | — |
| قلم | Peyda (محلی) + Vazirmatn | — |

بدون کتابخانهٔ مدیریت state، بدون UI kit بیرونی: همهٔ کامپوننت‌ها در `src/shared/ui` ساخته شده‌اند تا با سیستم طراحی غنیمت یکی باشند.

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # بررسی تایپ + خروجی در dist
npm run preview
```

ورود: هر شمارهٔ نمونه از صفحهٔ ورود، کد `111111`. نوار «نسخهٔ نمایشی» بالای پنل نقش، حالت صفحه و پاسخ سرویس‌های بیرونی را عوض می‌کند و دادهٔ نمونه را بازنشانی می‌کند.

## ساختار پوشه‌ها

```
src/
  main.tsx                 ورود برنامه (HashRouter یا MemoryRouter)
  App.tsx                  همهٔ مسیرها و محافظ نقش
  styles.css               توکن‌های طراحی (روشن/تیره) و پایهٔ Tailwind
  fonts/                   قلم Peyda
  admin/
    shell/                 قاب پنل: منوی کناری (nav.ts)، سربرگ، نوار نمایشی، ۴۰۴
    pages/                 صفحه‌های اصلی چندبخشی (سفارش‌ها، عملیات، مردم، درآمد، سازمان…)
    catalog/ merch/ partner/ print/ orders/ insight/ site/ builder/ blog/ cx/ people/ pro/ …
                           هر ماژول در پوشهٔ خودش
  shared/
    data/                  تایپ‌ها و دادهٔ نمونهٔ هر دامنه (seed.ts مرکز آن است)
    lib/                   store (داده و نشست)، fa (اعداد و تاریخ)، profit، barcode، image
    ui/                    کامپوننت‌های مشترک (Page، DataTable، Drawer، Modal، Select، charts…)
    icons/
  storefront/              پیش‌نمایش ویترین برای تنظیمات سایت
public/logos/              لوگوی بانک‌ها، درگاه‌ها و سرویس‌های ایرانی (معمولی و سفید)
docs/developer/            همین مستندات
docs/screens/              تصویر صفحه‌ها
docs/releases/             یادداشت هر نسخه
scripts/docgen/            تولید خودکار مستندات و تصاویر
```

## حالت بازبینی تیم

دکمهٔ «ثبت نظر» پایین صفحه (`src/shared/ui/review.tsx`) برای بازبینی تیم طراحی است: هر بخش را انتخاب می‌کنند و یک Issue پرشده با برچسب «نظر طراحی» در مخزن باز می‌شود. **در نسخهٔ تولید با `VITE_REVIEW=off` خاموش شود.**
