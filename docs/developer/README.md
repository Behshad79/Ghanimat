## فایل‌های ماشینی

| فایل | کاربرد |
|---|---|
| [`openapi.yaml`](openapi.yaml) | اسکیمای OpenAPI 3 برای Swagger/Postman و تولید کد کلاینت و سرور |
| [`data-model.json`](data-model.json) | فیلدها و نوع هر مجموعه |
| [`sample-db.json`](sample-db.json) | دادهٔ نمونهٔ کامل پنل، برای seed پایگاه‌داده و تست‌ها |
| [`design-tokens.json`](design-tokens.json) | توکن‌های طراحی (W3C DTCG، روشن و تیره) برای Tokens Studio / Figma Variables / Style Dictionary |
| [`../screens/`](../screens) | تصویر همهٔ صفحه‌ها (دسکتاپ، موبایل، تیره) |

## به‌روز ماندن

سندهای ۰۳ تا ۰۸ و فایل‌های ماشینی **از روی کد تولید می‌شوند** و با هر انتشار دوباره ساخته می‌شوند:

```bash
python3 scripts/docgen/gen.py
```

تغییرات هر نسخه و کارهایی که توسعه باید انجام دهد در [`../releases/`](../releases) و [`../../CHANGELOG.md`](../../CHANGELOG.md) است.
