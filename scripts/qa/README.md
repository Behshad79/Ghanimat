# آزمون خودکار پنل

سه ابزار برای تکرار آزمون‌های کیفیت. پیش از اجرا، نسخهٔ ساخته‌شده را روی پورت 4174 بالا بیاورید:

```bash
npx vite build --outDir /tmp/gh-dist && npx vite preview --outDir /tmp/gh-dist --port 4174
```

| فایل | کار | اجرا |
|---|---|---|
| `crawl.cjs` | همهٔ مسیرها با همهٔ نقش‌ها: خطای اجرا، خطای کنسول، سرریز افقی، تصویر شکسته، متن undefined/NaN | `USERS=u1,u2 W=1440 node scripts/qa/crawl.cjs` |
| `harness.mjs` | سناریوهای منطق کسب‌وکار روی لایهٔ داده (یکتایی برچسب، رسید و حوالهٔ تکراری، موجودی منفی، تطبیق پول، ووکامرس با کد محموله، برگشت دوباره) | `node scripts/qa/harness.mjs` |
| `flows.cjs` | سناریوهای رابط در مرورگر (تحویل، لغو با دلیل، چاپ سریع و PDF، فروش حضوری، اسکن حواله، گزارش سرمایه‌گذار، دید شریک) | `node scripts/qa/flows.cjs` |

نقش‌ها: u1 مدیر کل، u2 عملیات، u3 اپراتور ساده، u4 شریک (یاسین)، u5 پشتیبانی، u6 مالی، u7 رشد، u8 کنترل کیفیت، u9 دستیار مدیر کل.
