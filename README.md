# غنیمت (Ghanimat)

پروتوتایپ قابل‌اجرای «مرکز فرماندهی غنیمت» (پنل ادمین)، با دادهٔ نمونه. سایت مشتری و پنل مشتری در مرحله‌های بعد به همین مخزن اضافه می‌شود (`src/storefront`).

این نسخه محصول نهایی نیست؛ مرجع دقیق طراحی و توسعه است. بک‌اند ندارد و همه‌چیز در مرورگر اجرا می‌شود.

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخهٔ ایستا: `npm run build` (خروجی در `dist`). با هر push روی `main`، گردش‌کار `.github/workflows/deploy.yml` نسخهٔ نمایشی را روی GitHub Pages منتشر می‌کند (یک بار در تنظیمات مخزن، Pages › Source را روی «GitHub Actions» بگذارید).

## حساب‌های نمونه

کد ورود برای همه: `111111`. در نوار «نسخهٔ نمایشی» بالای پنل می‌توان بدون خروج نقش را عوض کرد.

| شماره | نقش | چه چیزی باز می‌شود |
|---|---|---|
| 09000000001 | مدیر کل | پنل کامل، همهٔ ماژول‌ها، «مشاهده به‌جای…» |
| 09000000002 | مدیر عملیات | سفارش‌ها، انبار، ارسال، مرجوعی |
| 09000000003 | اپراتور ساده | حالت ساده (`/simple`) |
| 09000000004 | شریک انبار مهاباد | پرتال شریک (`/partner`) |
| 09000000005 | کارشناس پشتیبانی | صندوق ورودی |
| 09000000006 | کارشناس مالی | مالی و تسویه |
| 09000000007 | مارکتینگ، سئو و رشد | مارکتینگ، سئو، رشد، تحلیل |
| 09000000008 | کارشناس کنترل کیفیت و انبار | صف‌های انبار |

## نوار «نسخهٔ نمایشی»

- **تعویض سریع نقش**
- **منوی حالت‌ها:** عادی، خالی، بارگذاری، خطا، بدون دسترسی، آفلاین (روی هر صفحه اعمال می‌شود)
- **نتیجهٔ سرویس‌های بیرونی:** موفق، ناموفق، کند (روی خواندن لینک پیک، استعلام تراکنش، چاپ، پیامک آزمایشی و دستیار اثر دارد)
- **بازنشانی دادهٔ نمونه:** تغییرها در `localStorage` مرورگر می‌ماند تا بازنشانی شود

## ساختار

```
src/
  styles.css            توکن‌های طراحی (رنگ، تایپ، شعاع، تراکم، تم تیره)؛ تنها منبع مقدارها
  shared/
    lib/fa.ts           ارقام فارسی، تومان، تاریخ جلالی، زمان نسبی، خروجی CSV
    lib/store.ts        دادهٔ نمونهٔ ماندگار، نشست، نقش‌ها، دسترسی، شبیه‌ساز سرویس بیرونی
    data/seed.ts        مجموعه‌دادهٔ واحد (محصول، واحد، سفارش، مرسوله، مشتری، تیکت، …)
    data/statuses.ts    جدول واژگان وضعیت‌ها و Glossary
    data/hints.ts       متن هینت‌ها
    ui/                 کامپوننت‌ها: base، overlay (مودال، کشو، Toast، تأیید، هینت)، table، charts، page
  admin/
    shell/              Sidebar، Top Bar، ناوبری موبایل، Command Palette، دستیار غنیمت
    pages/              ماژول‌های پنل کامل
    simple/             حالت ساده (اپراتور کم‌تجربه)
    partner/            پرتال شریک انبار
  storefront/           جای سایت و پنل مشتری (مرحلهٔ بعد)
```

افزودن صفحهٔ تازه: یک کامپوننت با `<Page title module …>` بسازید، مسیر را در `src/App.tsx` و آیتم منو را در `src/admin/shell/nav.ts` اضافه کنید. `Page` خودش دسترسی نقش و منوی حالت‌ها را اعمال می‌کند.

## آنچه شبیه‌سازی شده و باید در نسخهٔ واقعی ساخته شود

- همهٔ سرویس‌های بیرونی (درگاه، سرویس‌های اقساطی، پیامک، پیک، پست، کانال‌های فروش، استعلام‌ها) پاسخ نمونه می‌دهند.
- دستیار غنیمت پاسخ‌گوی قاعده‌محور روی همان دادهٔ نمونه است، نه مدل زبانی.
- ورود، مجوزها و لاگ ممیزی فقط سمت مرورگر است.
- اسکن بارکد، دوربین، قلم، پوش و ورودی صوتی جای‌گذاری شده‌اند.
- آیکون‌ها از Lucide است؛ خانوادهٔ Magicoon روی npm نیست و باید جایگزین شود.
- عدد شاخص‌های داشبوردهای رشد، سئو، مارکتینگ و زیرساخت ثابت و نمایشی است.

## عکس کالاها
عکس‌های دادهٔ نمونه، عکس‌های جایگزین با مجوز آزاد از Wikimedia Commons هستند (نام سازنده و مجوز هر فایل در `public/products/CREDITS.md`). جای آن‌ها باید عکس واقعی هر واحد گذاشته شود. کالای بدون عکس، آیکون دسته‌اش را نشان می‌دهد.

## کنتراست
نتیجهٔ ممیزی WCAG AA در `docs/contrast-audit.md`. برای اجرای دوباره: پس از `npm run build` و `npx vite preview --port 4173`، دستور `node scripts/contrast-audit.cjs`.

## راهنمای طراحی

- مشخصات کامل: سند «پرامپت جامع طراحی UI/UX پنل ادمین غنیمت» (نسخهٔ ۵).
- اسکیل `design-taste-frontend` (taste-skill، MIT) در `.claude/skills/design-taste-frontend`؛ چه بخشی از آن در پنل اعمال می‌شود در `VENDORED.md` همان پوشه آمده است.
- اسکیل `ui-ux-pro-max` (MIT) در `.claude/skills/ui-ux-pro-max` قرار دارد و برای بازبینی UI استفاده می‌شود. توصیهٔ سبک آن («Minimalism & Swiss»، تراکم داشبوردی، حرکت حداقلی) با طراحی هم‌راستاست؛ رنگ و فونت پیشنهادی آن اعمال نشده، چون توکن‌های برند غنیمت (آبی `#0000FF` و Vazirmatn) اولویت دارند. قواعد اعمال‌شده: هدف لمسی ۴۴، فونت ۱۶ ورودی‌ها در لمسی، Focus واضح، `prefers-reduced-motion`، وضعیت با رنگ + متن، جدول به کارت در موبایل.
- قرارداد نمودارها: محور زمان در کل پنل از چپ به راست.
